# M1 · Ranker de transacciones

Generado por `make train` (`src/models/m1/train.py`). Versión `m1-lgbm-1`. Fuente de datos: **synthetic_replica** (réplica sintética: los números no son del dataset real).

Las consultas son **sintéticas**: cada una toma un cargo real de un cliente (de la tabla gold) y genera lo que el cliente diría con ruido realista (montos redondeados, ±1–5 días, apodos del comercio, 35–40% de datos faltantes, tarjeta equivocada a veces). 12% describen un cargo que no está entre los candidatos.

- Partición temporal: entrenamiento < 2025-12-01 ≤ validación < 2026-03-01 ≤ prueba.
- Tamaños: train 30,000 consultas (64,148 candidatos), calib 12,000 consultas (25,779 candidatos), val 8,000 consultas (31,022 candidatos), test 8,000 consultas (33,107 candidatos).
- Modelo: LightGBM LambdaRank, 318 árboles; se evalúa en Python puro dentro de la Lambda (diferencia máxima con lightgbm: 1.1e-14).
- Calibración: un modelo de confianza (LightGBM binario, entrenado en una partición de calibración que el ranker no vio) estima P(el primero es el cargo) por su ajuste absoluto; isotónica en validación. ECE del top-1 0.025 (softmax crudo) → 0.021.
- Umbrales elegidos en validación: confirmar si p ≥ 0.95, ofrecer opciones si p ≥ 0.15, si no preguntar.
